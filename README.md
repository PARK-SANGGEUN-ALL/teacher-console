# 모두의 생기부 정성평가 상담 콘솔

**Copyright@All Teachers**

대학 학생부종합전형 가이드북 **2개년 45종 · 1,526면**을 진학 상담용으로 색인한 웹 도구입니다.
설치나 서버 없이 정적 파일만으로 동작합니다.

- **2027학년도** 가이드북 20종 — 우수 평가사례 중심
- **2026학년도** 가이드북 25종 — 전문 수록

## 화면

| 탭 | 쓰임 |
| --- | --- |
| 평가 루브릭 | 10개 항목을 4단계로 표시 → 진단 요약·면접 질문·학생 과제 자동 생성 |
| 주제별 색인 | 학업·탐구·진로·공동체·출결·면접 등 11개 주제별로 45종의 해당 지면 모아보기 |
| 학과 사례 | 계열·학과명으로 합격 사례 지면 찾기 (87건) |
| 대학별 보기 | 대학별 평가 항목 지면·합격 사례·전체 지면 |

지면 번호나 썸네일을 누르면 원문이 열립니다. 좌우 화살표·손가락 밀기로 이동하고,
이미지를 누르면 원본 해상도로 확대됩니다. 휴대폰 뒤로가기를 누르면 앱이 닫히지 않고
보던 목록으로 돌아옵니다.

## GitHub Pages 배포

1. 이 폴더의 내용을 저장소 루트에 올립니다.
2. Settings → Pages → Source를 `Deploy from a branch`, 브랜치를 `main` / `(root)`로 지정합니다.
3. 몇 분 뒤 `https://<계정>.github.io/<저장소>/` 로 열립니다.

`.nojekyll` 파일이 포함되어 있어야 이미지 폴더가 그대로 서비스됩니다. 지우지 마세요.

이미지가 1,500여 개라 웹 업로드 화면(드래그 앤 드롭)은 한 번에 100개 제한이 있습니다.
Git 명령으로 올리시는 편이 확실합니다.

```bash
git init
git add .
git commit -m "생기부 정성평가 상담 콘솔"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

## 구성

```
index.html      단일 페이지 앱 (외부 의존성 없음, 글꼴만 CDN)
img/            지면 원본 1,526장 (WebP, 가로 1500px)
thumb/          목록용 축소본 1,526장 (WebP, 가로 300px)
og.png          링크 공유 시 표시되는 미리보기 이미지
favicon.png     탭 아이콘
.nojekyll       GitHub Pages 설정
```

파일명은 `연도-대학코드-면번호.webp` 형식이며 모두 영문·숫자입니다.

## 저작권

수록 자료의 저작권은 각 대학에 있습니다. 교내 진학 상담 목적으로만 이용하세요.
평가 루브릭의 단계 기준은 가이드북에 공통으로 나타나는 평가요소를 상담용으로 정리한 것으로,
역량별 반영비율과 세부 명칭은 대학마다 다릅니다. 최종 판단은 지망 대학의 원문 지면을 확인하세요.

## 배포 후 확인할 것

카카오톡·페이스북에 링크를 올렸을 때 미리보기 이미지가 안 뜨면,
`index.html` 위쪽의 주석 표시된 세 줄을 실제 주소로 바꿔주세요.

```html
<meta property="og:url"      content="https://<계정>.github.io/<저장소>/">
<meta property="og:image"    content="https://<계정>.github.io/<저장소>/og.png">
<meta name="twitter:image"   content="https://<계정>.github.io/<저장소>/og.png">
```

카카오톡은 한 번 읽은 미리보기를 캐시에 오래 보관합니다.
바꾼 뒤에도 예전 화면이 뜨면 카카오 디벨로퍼스의 캐시 초기화 도구를 쓰거나,
링크 끝에 `?v=2` 를 붙여 공유해 보세요.

## 저장소 공개 범위

GitHub Pages는 무료 요금제에서 **공개(public) 저장소만** 사이트로 서비스됩니다.
공개로 올리면 수록된 대학 가이드북 지면이 인터넷 누구에게나 열립니다.
교내 공유가 목적이라면 아래를 먼저 검토하세요.

- 각 대학이 홈페이지에 공개 배포한 자료인지 확인
- 필요하면 특정 대학 자료를 `img`/`thumb`에서 빼고 배포
- 또는 유료 요금제의 비공개 Pages, 학교 내부망, 구글 드라이브 공유 활용
